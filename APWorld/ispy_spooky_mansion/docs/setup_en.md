# I Spy Spooky Mansion Deluxe - Setup Guide

## What you need

- The I Spy Spooky Mansion Deluxe Python port with Archipelago support (this repository's launcher / `ispy.main`),
  set up with your own copy of the game disc as usual.
- The `ispy_spooky_mansion.apworld` file, installed through the Archipelago Launcher ("Install APWorld").

## Generating a game

1. Create your YAML (the Archipelago Options Creator lists every option of this game).
2. Put it with the other players' YAMLs and generate as usual.
3. Host the result (or use the Archipelago website) and note the address and your slot name.

## Playing

1. Start the game and click the help button in the top-right corner: it opens the Archipelago menu.
2. Enter the server address (host:port), your slot name and the password if there is one, then Connect.
   On a brand-new save the menu is shown automatically before the "Choose an Ending" screen.
3. Your options decide which endings (waves) you can play. Use the wave buttons in the menu to switch between
   them; every wave keeps its own progress.
4. Checks are sent as you play. Items you receive show as short messages; "You Found Me" is the filler item.

## Notes

- Riddle rando takes effect from the next wave or a new game, because the riddles are chosen when a wave is built.
- A save made before connecting is not reshuffled; start a new save for a fresh run.
