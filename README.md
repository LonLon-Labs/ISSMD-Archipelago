# I Spy Spooky Mansion Deluxe Archipelago

An Archipelago integration of the python port of I Spy Spooky Mansion Deluxe.

## Run

### Automatically
Download the executable for your Operating System and CPU architecture in the [releases](/releases) tab.

Run the executable and select your legally obtained ISO file (first run only).

The game will automatically start.

### Manually
```
pip install pygame
python -m launcher
```
Saves go to `%LOCALAPPDATA%\ISpySpookyMansionArchipelago\SAVED GAMES\<player>\`.
